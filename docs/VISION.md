# Замысел и цель zer0-waypass

## Проблема

Пользователь работает с большим количеством Firefox- и Chromium-подобных
браузеров. Расширение менеджера паролей приходится устанавливать, связывать и
обслуживать в каждом браузере. Некоторые интеграции регулярно требуют повторной
авторизации. Нужен один системный сценарий, одинаковый для любого приложения.

## Задумка

`zer0-waypass` открывается глобальной горячей клавишей и показывает системный
поиск по учётным записям:

```text
SUPER+P -> поиск "github" -> выбрать account -> скопировать -> Ctrl+V
```

Пользователь видит только имя/путь записи из `gopass`. Username и пароль
расшифровываются только после явного действия пользователя и сразу направляются
в sensitive Wayland clipboard. Через настраиваемое время clipboard перестаёт
отдавать секрет.

## Пользовательская ценность

- один UX для любого количества браузеров;
- отсутствие привязки к API конкретного облачного password manager;
- локальное управление данными;
- пригодность для терминала и desktop-приложений;
- возможность самостоятельно хранить и синхронизировать зашифрованные записи;
- community-плагин, которым смогут пользоваться другие пользователи Noctalia.

## MVP

- поиск записей `gopass`;
- launcher prefix `/wp` и отдельная системная панель;
- copy username;
- copy password;
- sensitive clipboard с TTL;
- понятные состояния backend missing/error и ожидания pinentry;
- документация исключения sensitive clipboard из сторонних clipboard managers;
- отсутствие секретов в state и логах; в истории — для документированной и
  проверенной clipboard-конфигурации.

## Не входит в MVP

- браузерные расширения;
- автоматическое определение URL активной вкладки;
- автоматическая вставка и отправка форм;
- собственное шифрование;
- собственный сетевой sync-сервер;
- импорт всех форматов password managers;
- мобильное приложение;
- изменение пользовательских конфигов без явного действия пользователя.

## Долгосрочное направление

После MVP возможны:

1. Git sync зашифрованного password store через собственный SSH remote.
2. Поддержка нескольких stores и GPG recipients.
3. Независимый Wayland UI для пользователей без Noctalia.
4. Arch package, Nix package и другие дистрибутивные пакеты.
5. Опциональный browser bridge как отдельный модуль, не обязательный для core.

## Критерий успеха

Пользователь вызывает `SUPER+P`, находит нужную запись, копирует значение и
вставляет его. Частота запроса passphrase определяется пользовательской политикой
`gpg-agent`. После TTL секрет отсутствует в текущем clipboard; в проверенной
конфигурации sensitive-aware `cliphist` он также не появляется в истории.
