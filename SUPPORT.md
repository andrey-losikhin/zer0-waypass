# Support

zer0-waypass is an experimental personal project. Best-effort support is
provided through GitHub Issues for the documented MVP environment: Linux,
Wayland, Noctalia Plugin API 24+, `gopass` with GPG and `wl-copy`.

Before reporting a problem, check [installation](docs/INSTALL.md),
[clipboard behavior](docs/CLIPBOARD.md), existing issues and the latest release.
Provide component versions, compositor/distribution details and a reproducer
using synthetic data. Redact entry names, usernames, URLs, paths and logs.

Do not use public issues for vulnerabilities; follow [SECURITY.md](SECURITY.md).
Configuration of GPG, gopass, Noctalia, the compositor and clipboard managers
outside this project's documented integration is not a supported help-desk
service.
